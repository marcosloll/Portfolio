## Sobre o projeto

Este é o código-fonte do meu portfólio pessoal. A página reúne meus principais projetos, as tecnologias que estou estudando e formas de contato.

O projeto foi desenvolvido com HTML, CSS e JavaScript, com layout responsivo, animações de entrada e uma identidade visual inspirada em interfaces futuristas.
